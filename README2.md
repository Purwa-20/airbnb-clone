# Airbnb Clone

A full-stack Airbnb-inspired web application that allows users to explore property listings, view details, and manage bookings.

##  Features

* User authentication (Signup/Login)
* Browse and search property listings
* View detailed property information
* Booking system functionality
* REST API integration
* Responsive UI design

##  Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Databases: MongoDB, SQL
* APIs: Custom REST APIs

##  How to Run Locally

1. Clone the repository
2. Install dependencies using `npm install`
3. Start server using `npm start`
4. Open in browser at `localhost:3000`
